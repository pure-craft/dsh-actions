## English

Public docs under `docs/` come in two kinds: **features** (per-topic reference) and **scenarios** (walkthroughs). Both are bilingual — Chinese is the `.md`, English is the sibling `.en.md` in the same directory, and both must be updated together.

For the project overview and install instructions, start at the repository's [README.en.md](https://github.com/pure-craft/dsh-actions/blob/main/README.en.md).

**Scenarios** (when and how to use it) — see the table above, English column.

**Features** (per-topic reference) — see the table above, English column.

**Assets** — `assets/` holds the screenshots, shared by both languages; READMEs and docs always reference them through absolute `raw.githubusercontent.com` URLs.
